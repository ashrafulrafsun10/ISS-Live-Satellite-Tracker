# 🛰 ISS Live Satellite Tracker

A real-time web application that tracks the International Space Station (ISS) using live satellite data and displays its current position on an interactive world map.

## 🚀 Features

- 🌍 Live ISS Position Tracking
- 🛰 Real-Time Latitude & Longitude
- 📏 Live Altitude
- ⚡ Live Velocity
- 🗺 Interactive World Map (Leaflet.js)
- 📍 Current Country / Ocean Detection
- 🛰 ISS Orbit Trail
- ⏱ Automatic Update Every 5 Seconds
- 📱 Responsive Design
- ✨ Modern Glassmorphism UI

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Leaflet.js
- OpenStreetMap
- Where The ISS At API
- Nominatim Reverse Geocoding API
